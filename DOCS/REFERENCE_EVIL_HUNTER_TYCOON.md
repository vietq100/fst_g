# REFERENCE — Evil Hunter Tycoon (Super Planet)

Research notes from public guides (web search, Oct 2026). Secondary sources, partly outdated — verify numbers before copying.

## Core loop
Town chief builds facilities → hunters (auto, no manual control) fight in "evil lands" → gather materials → sell via Trading Post → chief crafts gear/food/potions → hunters buy/equip → stronger hunters clear dungeon raids/bosses → reincarnate → higher difficulty.

## Buildings (unlocked by Town Hall level)
| Building | Function |
|---|---|
| Town Hall | Gate of progression: its level unlocks/upgrades other buildings |
| House | Raises max hunter count |
| Trading Post | Chief requests materials; hunters farm and sell them; chief pays gold on completion |
| Restaurant | Food for hunger (satiety drops while fighting; hungry hunters return to town) |
| Tavern | Drinks → mood |
| Inn | Rest → stamina |
| Infirmary | Heals injured hunters (needs healing items prepared by chief) |
| Blacksmith / Weapon shop / Armor shop | Craft and sell gear |
| Enhancement Forge | Upgrade gear |
| Academy | Learn skills, traits, secret techniques, class change |
| Sanctuary of Resurrection | Revives dead hunters |
| Reincarnation Portal | Reincarnate level-100 hunters (gates higher difficulty) |

## Hunters
- Recruited with invitation scrolls; capped by housing.
- Classes: Berserker (melee), Ranger (kite/slow, multishot), Paladin (tank), Sorcerer (magic DPS). Each has 2 subclasses after 5 reincarnations + Lv100 (Academy, expensive).
- Reincarnation at Lv100 grants points → traits (stronger than secret techniques).
- Positive/negative traits (Coward, Lazy…) — players ban bad ones.
- Gear tiers: Common → Rare → Superior …; keep gear/building levels matched to difficulty.

## Difficulty
Easy first; harder modes unlock by number of reincarnated hunters. Buildings must be levelled to sell gear of matching level.
