# UI DESIGN

## Visual identity

UI should feel like:
- fantasy management interface
- clean
- readable
- slightly dark
- warm accents

## Main HUD

Top:
- Gold
- Dark Essence
- Warehouse usage (slots used / capacity)
- Town level

Side/bottom:
- Hunter status
- Expedition status

## Panels

### Hunter panel
Show:
- portrait
- name
- class
- level
- HP
- XP
- equipment
- traits
- mood (icon/colour state)
- current activity (resting / training / socializing / recovering)
- bonds (who they are close to)
- short history (expeditions, bosses, injuries)

### Building panel
Show:
- building name
- level
- function
- upgrade cost
- requirements

### Expedition panel
Show:
- destination
- recommended level
- enemy preview
- rewards
- selected Hunters (show mood, traits and bonds that affect the party)
- start button

## Buttons

Buttons must clearly communicate:
- available
- unavailable
- selected
- dangerous

Avoid tiny text.

## Feedback

Use:
- floating damage numbers
- loot popup
- level-up effect
- notification
- progress bars

Do not overwhelm the screen.
