# BOSS DESIGN

## First Boss: Forest Guardian

## Visual

Large ancient forest creature.

Shape language:
- heavy
- rooted
- slow
- powerful

Features:
- branch-like horns
- stone bark armor
- glowing core
- large hands

## Combat identity

The boss should feel different from normal enemies.

Attacks:
1. basic melee
2. ground shockwave
3. periodic area attack

MVP can implement only basic melee first.

## Arena

Boss arena:
- larger open space
- minimal obstacles
- clear combat area
- distinct visual landmark

## Reward

MVP (values in `BALANCE.md`):
- large gold reward
- Iron Ore, Beast Fang, Dark Essence
- chance for Rare equipment
- first clear unlocks Town Hall level 2
- mood and history gain for participating Hunters

Later: unlock new expedition content when more regions exist.

Bosses are milestones, not endings. The boss is repeatable with reduced rewards on repeat clears.
