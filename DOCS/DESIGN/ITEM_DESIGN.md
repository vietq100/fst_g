# ITEM DESIGN

## Visual principles

Items must be recognizable from icons.

MVP item categories:
- weapon
- armor
- material

Consumable exists as a data category but has no items in MVP.

MVP item list and stats: `BALANCE.md` → Equipment.

## Rarity

Common
Uncommon
Rare

Use a consistent visual language for rarity.

## Weapons

MVP (Warrior only):
- Rusty Sword
- Iron Sword
- Fang Blade

Later classes:
- Hunter Bow
- Apprentice Staff

## Armor

MVP:
- Leather Armor
- Iron Armor

## Materials

MVP:
- Iron Ore
- Beast Fang
- Dark Essence (rare)

Materials are stackable inventory items, not a separate currency. Gold is the only currency.

## Icon design

Target:
- 32x32 or 48x48 UI icon
- centered object
- simple silhouette
- minimal background noise

## Equipment

Equipment should communicate:
- type
- rarity
- power
